# 最终图表质量检查

## 内容与一致性

- [ ] 每张图对应一个真实论点。
- [ ] 数据、时间范围、单位和统计口径与代码、Excel、正文一致。
- [ ] 模型名、参数、方案名和数值没有旧版本残留。
- [ ] 正文先引用图，图题编号连续且对应。
- [ ] 图表能由提交代码生成，或已说明素材来源。

## 可读性与碰撞

- [ ] 最终 PDF 100% 比例下无需放大即可读清。
- [ ] 图例未遮挡曲线、柱体、散点、置信带或标注。
- [ ] 多子图无重复图例、标题贴图、标题贴图例或相邻面板重叠。
- [ ] 坐标轴、刻度、单位、颜色条、数据标签和箭头无错位或裁切。
- [ ] 横轴不过密；必要时减少刻度、换行、旋转、扩图或拆图。
- [ ] 文字颜色足够深，细线打印时仍清楚。

## 视觉语义与导出

- [ ] 同一方案跨图颜色和线型一致。
- [ ] 图例顺序与系列出现顺序一致。
- [ ] 灰度打印和色觉异常情况下仍可区分主要系列。
- [ ] 误差棒、置信带和显著性标记有真实统计依据。
- [ ] 数据图优先提供 PDF/SVG；位图有效分辨率不低于 300 dpi。
- [ ] 字体跨设备测试通过，无中文方框或负号乱码。
- [ ] 图片边缘、图例、标题和箭头完整，没有被裁切。
- [ ] 修改源图后已重新导出并替换论文旧图。
- [ ] 论文重新编译后完成逐页复检。

## 流程图专项

- [ ] 总图体现各问递进和数据传递。
- [ ] 分问图体现真实步骤、判断、循环和回退。
- [ ] 判断节点标明“是/否”，箭头无断线、交叉和错误指向。
- [ ] STEP 顺序与主流程、正文和代码一致。
- [ ] 框内文字不溢出、不贴边，不拆开变量或单位。

任一关键遮挡、错位、不可读、数据不一致或导出缺失均阻断交付。修复后重新导出，并从最终 PDF 再检查一次。
