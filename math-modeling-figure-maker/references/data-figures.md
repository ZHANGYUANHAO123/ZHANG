# 数据图与多面板图规范

## 选图

| 论证目标 | 首选图形 | 常见误用 |
|---|---|---|
| 时间变化与调度 | 折线、阶梯图、面积图 | 柱状图塞入过密时点 |
| 类别或方案比较 | 排序柱状图、点图 | 3D 柱、截断纵轴夸大差异 |
| 连续变量关系 | 散点图、回归或参考线 | 将无序类别用折线连接 |
| 单变量分布 | 直方图、ECDF、箱线/小提琴 | 饼图或只画均值柱 |
| 矩阵与时段结构 | 热力图 | 无颜色条的连续着色 |
| 构成与能量平衡 | 堆叠柱/面积图 | 类别过多的饼图 |
| 参数敏感性 | 折线、点图、热力图 | 雷达图堆叠过多方案 |
| 优化方案与约束 | 状态曲线、边界线、费用分解 | 只报目标值不画约束状态 |

小样本分组比较显示原始点。误差棒、分位带和置信带必须说明统计含义、样本量和计算方法。

## 证据类型

- 数据事实图：原始趋势、分布、相关、时段或空间结构。
- 过程证据图：预测误差、迭代收敛、权重、状态转移、参数选择。
- 结果图：最优方案、费用构成、调度曲线、对照实验、灵敏度或约束验证。

每问至少有一个直接回答题目的结果载体，但不机械凑固定数量。

## 多面板

- 整张图只回答一个核心问题。
- 主面板展示主要结果，辅助面板解释原因、误差或稳健性。
- 面板权重不同则采用非对称布局。
- 同一变量跨面板保持相同颜色、线型、名称和单位。
- 共享图例只保留一份并放在留白区或图外。
- 子图编号、标题基线、绘图区和坐标轴对齐。

## 可读性与视觉语义

- 字号按最终插入尺寸设定，不依赖后期缩放。
- 中文宜使用思源黑体、微软雅黑、等线等清晰字体。
- 避免浅灰细线和浅灰小字。
- 横轴过密时减少刻度、分层换行、旋转、扩图或拆图。
- 使用色盲友好的低饱和色板，同类方案跨图保持语义稳定。
- 灰度打印借助线型、点型或纹理区分。
- 柱状图纵轴原则上从零开始；断轴必须标明。
- 连续色图配置颜色条、单位和范围。
- 双 Y 轴优先改为共享横轴的上下子图。

图题说明对象和条件，正文说明图支持的判断。避免“结果如图所示”，不得把相关关系写成图表无法支持的因果结论。
