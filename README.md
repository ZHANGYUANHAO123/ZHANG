# CUMCM 数学建模 Skills

本仓库提供面向数学建模竞赛的可复用 Codex Skills。

## 数模竞赛画图手

`math-modeling-figure-maker` 用于选择、绘制、重排和审校数学建模论文的数据图、多面板图、总体建模流程图与分问算法流程图，重点解决字号过小、图例遮挡、文字重叠、布局错位、配色语义漂移和图表—代码—结果不一致。

安装地址：

```text
https://github.com/ZHANGYUANHAO123/ZHANG/tree/main/math-modeling-figure-maker
```

显式调用：

```text
$math-modeling-figure-maker
```

## 数学建模论文写作

`math-modeling-paper-writing` 面向数学建模竞赛论文的写作与终稿审校，覆盖摘要、问题分析、分问题求解、标题、公式、结果展示、图表说明和机械化表达清理。

本 Skill 通过补足“题目—模型—代码—图表—结论”证据链提高论文质量，不用于规避检测，也不允许虚构数据、参数、程序输出或参考文献。

## 在线安装

在 Codex 中直接输入：

```text
请从 https://github.com/ZHANGYUANHAO123/ZHANG 安装 math-modeling-paper-writing Skill
```

也可以将仓库地址交给 `skill-installer`：

```text
https://github.com/ZHANGYUANHAO123/ZHANG/tree/main/math-modeling-paper-writing
```

## 手动安装

下载仓库 ZIP，将 `math-modeling-paper-writing` 文件夹复制到：

```text
%USERPROFILE%\.codex\skills\
```

重新打开 Codex 任务后即可自动发现。也可以显式调用：

```text
$math-modeling-paper-writing
```

## 能力范围

- 从零撰写、按真实结果改写和终稿审校；
- 摘要逐问呈现模型与结果；
- 问题分析、模型假设和分问题求解结构优化；
- 公式、参数、代码、图表与结论一致性检查；
- 清理空泛套话、机械标题和模板化段落；
- 检查图表可读性、版面均衡和评委快速阅读效果。

## 真实性原则

不得虚构实验、指标、参数、文献或代码输出。降低“AI味”依靠补足事实、推理与结果证据，不靠故意制造错字、语病或规避检测。
